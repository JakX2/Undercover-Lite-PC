# Original PC keycap artwork (sources only)

These hand-authored SVG keycaps are **new artwork** for possible future Undercover Lite PC UI replacements.
They are not PCSX2 replacement files and have **no valid texture hash names**. Do not install them directly.

To use them after capturing an original Undercover prompt atlas, render the keycap to the atlas cell dimensions, preserve the original RGBA canvas, texture name, UV and transparency, and save a user-authored PNG replacement with the original PCSX2 hash. Verify against the real in-game control layout.

The six templates represent screenshot prompts: Cross → ENTER, Triangle → ESC, Square → BACKSPACE, Start → F, L1 → Q, and R1 → E. This is only a suggested distinct-key scheme, not a verified game mapping.
