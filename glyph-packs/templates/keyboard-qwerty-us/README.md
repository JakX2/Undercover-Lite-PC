# Keyboard QWERTY (US) blank template

This is **metadata only**, not a usable game texture pack. Create a sibling `replacements/` folder containing edited PNG/DDS images, retaining the exact hash filenames PCSX2 wrote in the dumps folder. Don't commit dumped original game artwork.

The prototype installer intentionally rejects empty packs. The game serial is fixed to `SLUS-21801`; a PAL or Japanese ISO needs its own correctly tested pack and serial.
